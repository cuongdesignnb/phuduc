# Accessibility Review

- Admin shell exposes a skip link, main landmark and labelled navigation.
- Shared confirmation dialog retains focus trapping, Escape handling and dialog semantics; PR3C adds an optional reason slot.
- Filters and date controls have accessible labels.
- Review ratings include text labels such as `5 trên 5 sao`, not stars as the only signal.
- Pagination exposes current page and Vietnamese labels.
